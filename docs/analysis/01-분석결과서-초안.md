## 1. 개요

### 1.1 목적

신규 웹앱(장치·모듈 배선 편집기)을 구축하기 위해 기능이 거의 같은 참고 서비스의 수집 자료를 분석한다. 분석 결과는 **모범사례·참고자료**로 쓰며, 기능마다 **짧은 설명과 원본 위치**를 남겨 추적성을 확보하는 데 목적이 있다. 모든 기능을 상세 명세하지는 않는다.

### 1.2 분석 방법

1. 파일 목록과 수집 로그(HTTrack)로 수집 범위와 누락 파일을 확인했다.
2. HTML에서 요소 ID, 버튼 제목(title), 모달 구조를 추출해 화면·기능 목록을 만들었다.
3. JS에서 모듈 머리 주석, 구획 주석(`// ---- … ----`), 함수 목록을 추출해 기능별 구현 위치를 연결했다.
4. v1과 v2 편집기 HTML의 요소 ID를 비교(`comm`)해 추가·삭제된 기능을 가려냈다.
5. 주석에 적힌 설계 판단(왜 이렇게 했는가)을 모범사례 후보로 따로 모았다.

### 1.3 위치 표기 규칙

| 별칭 | 실제 경로 |
|---|---|
| `V1/` | `ezcable v1/data/easycable/` |
| `V2/` | `ezcable v2/easycable.co.kr/` |

- JS 파일명의 캐시 꼬리표(`@v=…`, `0630` 등)는 생략한다. 예: `V1/js/app.js:2970` = `ezcable v1/data/easycable/js/app.js@v=7af9a090` 2970행
- 행 번호는 2026-09-30 기준 수집본의 행 번호다.

## 3. 분석 결과

### 3.1 제품 개요

이미지로 부품을 등록하고 단자를 찍은 뒤 단자끼리 배선을 그려 배선도를 만드는 **브라우저 전용 편집기**다. 도면에서 BOM(자재명세서)·배선 리스트(결선표)·PDF·PNG를 자동으로 만든다. 도면은 서버에 올리지 않고 브라우저(IndexedDB)와 `.ezc` 파일에만 저장하며, 서버는 계정과 이용권(Pro)만 관리한다.

### 3.4 데이터 모델 요약

`V1/js/model.js:69-82` 기준이다.

```
project
├─ meta { id, name, version, canvas{width:1600, height:900, grid:10, snap} }
├─ sheets[] { id, name, note, components[], wires[], annotations[] }
│   ├─ component { id, libraryId, name, x, y, rotation, scale, width, height, z, image, terminals[] }
│   │   └─ terminal { id, name, color, rx, ry }        ← 부품 기준 상대좌표(0~1)
│   ├─ wire { id, from, to, color, width, routing(ortho|straight), allowOverlap, waypoints[] }
│   │   └─ from/to = {componentId, terminalId} | {wireId, x, y}(분기)
│   └─ annotation (주석 텍스트)
├─ palette[] { color, label }                          ← 범례로 출력
└─ BOM 설정: manualBom, bomPrice, bomOrder, bomColShow, bomExtraCols, bomCustom, bomRowH, bomColW, bomColOrder

library part (IndexedDB): name, spec, folder, link, price, role(load|battery|converter),
                          volt, current, power, capacityAh, dod, duty, eff, datasheets[], terminals
저장 파일(.ezc): { format:"easycable", version:3, project, parts[], assets{} } → gzip
```

## 5. 주의사항

### 5.1 권리·이용 조건

- `V1/robots.txt:30`에 `Content-Signal: search=yes, ai-train=no, use=reference`가 선언돼 있다. 참고용 분석은 허용 범위지만, 학습 데이터로 쓰거나 대량 재배포하는 것은 운영자 의사에 반한다.
- 약관 제10조(`V2/terms.html:174`): **기본 부품·예시 도면 등 회사가 만든 자료의 권리는 회사에 있다.** 샘플 프로젝트, 예제, 공용 라이브러리 부품을 신규 앱의 샘플데이터로 **그대로 쓰면 안 된다.** 구조만 참고하고 샘플은 직접 만든다.
- 소스 코드, UI 문구, 디자인(CSS), 영상·이미지 에셋은 복제하지 않는다. v1 기획서 1장의 방침과 같다.

### 5.2 보안·위생

- **`V2/easycable.co.kr/index.html`에 외부 IP(`59.18.34.177`)로 가는 숨은 iframe이 들어 있다.** HTTP로 수집하는 과정에서 통신사 등이 삽입한 것으로 보이며, 원본 사이트 코드가 아니다. 이 파일은 열거나 배포하지 말고 삭제하는 것을 권장한다.
- 수집본에 외부 서비스 키(Supabase publishable key, Web3Forms access key)가 들어 있다. 공개용 키이긴 하지만 **신규 앱에 재사용하면 안 된다.**
- `ezcable v2/hts-cache/`, `hts-log.txt`는 수집 도구의 부산물이다. HTTrack 안내대로 공유하지 않는다.
